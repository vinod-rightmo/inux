# Repository conventions

Use Conventional Commits for changes to this repository, such as `feat:`,
`fix:`, `docs:`, and `chore:`. Mark breaking changes with `!` or a
`BREAKING CHANGE:` footer. Squash-merge feature PRs with a Conventional Commit
title so Release Please can determine the next version.

The conventions documented inside `skills/inux/` apply to projects using the
skill; this file defines the Inux repository's own commit convention.
